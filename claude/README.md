# Claude Code adapter

`./install.sh claude` installs `shared/AGENTS.md` followed by `claude/harness.md` as `~/.claude/CLAUDE.md`, the skills, and the `researcher` and `worker` subagents, on Sonnet 5.5 (`model: sonnet`) at `effort: high` for `worker` and `medium` for `researcher`; the main session stays on Opus 5.5. Use them only when no Herdr tab fits; the `delegate` skill runs delegated work in Herdr tabs you can watch. Claude delegate tabs start with `--settings ~/.agents/src/claude/delegate.json`, which denies `git push`, `gh pr create`, and `gh pr merge`. Claude Code subagents can only use Claude models. `researcher` has only `WebSearch`/`WebFetch` but still inherits `CLAUDE.md`, so it is told to send only sanitized public context. The installer merges two denies into `~/.claude/settings.json`, `Bash(git push:*)` and `Bash(gh pr merge:*)`, and removes the old `Agent`, `Task`, and `TeamCreate` denies; all other permissions and hooks stay yours. After you approve a push or merge, run it yourself with `! <command>`.

Check with `./install.sh --dry-run claude`, then start a new session.
