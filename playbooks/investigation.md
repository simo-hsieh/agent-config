# Playbook: investigation

For a question about code or behavior, or a request that is unclear. Work inline: no code edits and no questions to the user unless a decision is genuinely theirs.

1. **Read and probe.** Search first, then read ranged windows. Running read-only commands (tests, `--help`) is fine.
2. **Answer or plan.** Cite exact `file:line` for every claim and mark anything unproven as UNVERIFIED with the reason. For an unclear request, write a short plan and name the playbook the evidence points to.
