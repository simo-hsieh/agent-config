# Antigravity adapter

`./install.sh antigravity` installs `AGENTS.md`, the shared skills, and the subagents in `agents/` (`scout`, `worker`, `reviewer`) under `~/.gemini/config/`. The network-enabled researcher is not ported: it needs a privacy-boundary review first.

Tool lists and prompts are harness controls, not an operating-system sandbox. Check with `./install.sh --dry-run antigravity`.
