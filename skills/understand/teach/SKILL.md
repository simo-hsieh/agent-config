# Teach

1. From why I'm asking, pick the 2–3 things I should leave understanding.
2. Run `how`, `why`, or `auto-research` as needed, in parallel.
3. Explain: plain definition first, then the smallest complete answer. Stop and let me steer before going deeper.
4. Build diagrams incrementally: each one redraws the previous and adds one part.
5. Keep `why`'s stated / inferred / UNVERIFIED labels intact.
